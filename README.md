# 资金脉络｜A股板块资金流向本地版

这是一个运行在 macOS 或 Windows 本机的中文 A 股板块资金观察工具。它从公开行情页面读取行业与概念板块的资金净额数据，不需要付费 API 或密钥。

## 功能

- 沪、深、京 A 股行业及概念板块资金净流入/净流出排名
- 最新交易日每 5 分钟资金流向气泡回放；固定板块身份，气泡大小、上下位置与颜色随净额连续变化
- 真实五分钟观测自动写入本地 SQLite；关闭后重新打开仍可恢复，已保存的早盘数值不会被午后刷新静默改写
- 最多五个重点板块的日内资金轨迹
- 单个板块近三个月日频资金趋势、5 日及 20 日滚动均线
- 全市场“个股异动”页：中证全指分钟线、可缩放的显著事件标签、一分钟涨跌速与换手率 Top 10
- 个股详情页：最新价、买一/卖一、今开、最新收盘、日内区间、成交量/额、估值、市值，以及近三个月收盘价、5 日和 20 日均线
- 个股页排除 ST 与 *ST，覆盖沪、深、京主板、创业板、科创板和北交所
- 独立“策略模拟”页：用选择框配置选股范围、分钟涨速、行业确认、成交额/评分、买入延迟、成交价、仓位与退出规则
- 今日真实分钟回放：展示组合收益、现金/持仓、中证全指同期表现和买入事件，不写入持续账户
- 持久化模拟账户：现金、按交易所申报单位形成的持仓、买卖、收益曲线与策略版本保存在本地，重新打开后从已处理时点继续
- 按需生成约 28 秒、9:16、无音乐的 MP4 收盘视频
- 本地缓存；数据源短暂不可用时优先显示最近一次真实缓存

## 启动

### macOS

双击 `start.command`。程序会同时启动本地数据服务和网页，并打开：

`http://127.0.0.1:3000`

首次运行若 macOS 阻止脚本，可在终端中进入本目录并运行：

```bash
./start.command
```

### Windows 10 / 11

1. 安装 [Python 3.10 或更高版本](https://www.python.org/downloads/windows/) 和 [Node.js 22.13 或更高版本](https://nodejs.org/)。
2. 双击 `start-windows.bat`。
3. 首次启动会优先从国内 npm 镜像自动安装项目运行环境，时间取决于网络速度；不需要访问 GitHub，之后启动会更快。

程序准备完成后会自动打开默认浏览器。使用期间请保持启动窗口开启，关闭窗口即可停止本次启动的服务。未安装 FFmpeg 时，行情与图表仍可使用，但 MP4 生成功能不可用。

Windows 版会把 SQLite 行情记录保存到当前用户的 `%LOCALAPPDATA%\FundFlow`，因此不需要用管理员身份启动，也不会因为曾经以管理员身份运行而把数据库变成只读。

MP4 转换会依次寻找系统 `ffmpeg`、`FUND_FLOW_FFMPEG` 指定的程序，以及 Python `imageio-ffmpeg` 自带的可执行文件。当前 Mac 已安装后者，即使终端里没有全局 `ffmpeg` 命令，应用也能自动找到并转换视频。Windows 仍需安装 FFmpeg，或把 `FUND_FLOW_FFMPEG` 指向 `ffmpeg.exe`。

### 通过 U 盘或 SD 卡发送给 Windows 用户

在 Mac 上双击 `make-windows-transfer.command`，它会在项目文件夹的上一级生成一个名为 `fund-flow-windows-transfer-日期时间.zip` 的干净压缩包。把这个 ZIP 复制到 U 盘或 SD 卡即可。

Windows 用户必须先把 ZIP 完整解压到较短的英文路径（例如 `C:\fund-flow`），再双击其中的 `start-windows.bat`。不要直接在压缩包预览窗口内启动，也不要手动压缩 Mac 上包含 `node_modules` 的整个项目目录。

启动程序会检查依赖是否完整并且属于当前 Windows 处理器。如果收到的压缩包误带了 Mac 依赖或上次安装中断，程序会自动重新构建 Windows 依赖。若仍然失败，请发送同目录的 `startup-windows.log` 以便排查。

## 使用建议

收盘后点击“更新收盘数据”，等页面显示“已核验至 15:00”且分钟覆盖率达到 100% 后，即可点击“生成 28 秒 MP4”。视频会在最后 3 秒停留于真实 15:00 收盘帧，同时保存在 `output` 文件夹并由浏览器下载；若数据服务或 FFmpeg 不可用，按钮会在录制前直接说明原因。

分钟回放仅面向最新交易日。程序优先读取东方财富真实分钟资金历史，并将运行期间的东方财富或同花顺完整板块快照每五分钟保存到本机。公开源暂时受限时会保留最近一次已验证结果并继续重试；不会生成、预测或随机补齐气泡与趋势数据。

个股异动页使用中证全指作为全市场价格参考。程序先读取东方财富全市场短周期异动候选（上涨、下跌各 80 只），再丢弃源站涨速值，并用同一只股票相邻两个真实分钟成交价重新计算一分钟涨跌速；页面明确把它标为候选池重排，不冒充对近六千只股票逐只抓取后的全市场穷举。图表和榜单只显示至页面标出的“已核验”时间，收盘后停在 15:00。

个股详情把三类数据分开核验：快照和买卖盘使用东方财富与新浪，分时使用东方财富与腾讯，日线使用东方财富、腾讯与新浪。任一来源失败时会整段切换到另一个真实来源；不会把不同复权口径的日线混在一起，也不会为缺失的 Bid、Ask、估值或价格字段生成估计值。

策略实验室读取公开源仍可核验的当日异动、个股分钟、主营行业分钟价格/资金和中证全指分钟数据。今日回放从早盘到已核验时间按时间顺序执行，每次判断只看当时及更早数据，模拟成交使用用户选择的后续真实分钟。持续模拟则从用户点击启动的时点开始；只要本地启动窗口仍开着，即使浏览器停在其他页面，后台也会按分钟推进。关闭应用后账户仍保存在 SQLite，下次启动会先处理仍可核验的区间。若跨日存在无法恢复的数据缺口，程序会明确记录缺口而不会估算或补造交易。信号来自公开全市场短周期异动候选池的精确分钟重排，不冒充逐只扫描全部 A 股。

每次规则变更都会保存为新策略版本，只影响生效之后的新买入；已有持仓沿用开仓时的退出规则。A 股 T+1 约束下，当日买入不能卖出。数量按交易所规则计算：沪深普通 A 股按 100 股整数倍，科创板最低 200 股，北交所最低 100 股且可按 1 股递增。可选次一交易日开盘、09:31、止盈/止损后次日收盘或持续持有。收益图同时记录买入、卖出、规则变更及数据缺口，方便追溯结果是怎样形成的。

策略成本按比例账户估算：佣金 0.025%/边、经手及监管/过户估算 0.00541%/边、卖出印花税 0.05%、滑点 0.05%/边。因为账户名义本金未知，不计券商每笔最低佣金；页面会明确显示这一限制。所有结果都是观察性模拟，不连接券商，不构成投资建议。

## 数据说明

板块排名会优先使用东方财富公开行情，并在完整性校验失败时自动切换到同花顺公开网页；指数另有新浪公开行情备用源。不同来源对“大单/资金净额”的统计口径可能不同，因此程序按来源分别保存，不会把不同网站的数值平均或拼成一条连续曲线。行业与概念板块的成分会重叠，因此板块净额不能直接相加解释为全市场净流入。

本工具仅供信息展示，不构成任何投资建议。

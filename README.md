# 资金脉络｜A股板块资金流向本地版

这是一个运行在 Mac 本机的中文 A 股板块资金观察工具。它从公开行情页面读取行业与概念板块的资金净额数据，不需要付费 API 或密钥。

## 功能

- 沪、深、京 A 股行业及概念板块资金净流入/净流出排名
- 最新交易日每 5 分钟资金流向气泡回放；固定板块身份，气泡大小、上下位置与颜色随净额连续变化
- 最多五个重点板块的日内资金轨迹
- 单个板块近三个月日频资金趋势、5 日及 20 日滚动均线
- 按需生成约 28 秒、9:16、无音乐的 MP4 收盘视频
- 本地缓存；数据源短暂不可用时优先显示最近一次真实缓存

## 启动

双击 `start.command`。程序会同时启动本地数据服务和网页，并打开：

`http://127.0.0.1:3000`

首次运行若 macOS 阻止脚本，可在终端中进入本目录并运行：

```bash
./start.command
```

## 使用建议

收盘后点击“更新收盘数据”，等气泡回放完成读取后即可点击“生成 28 秒 MP4”。生成的视频同时保存在 `output` 文件夹并由浏览器下载。

分钟回放仅面向最新交易日。部分刚调整或新设的板块可能没有公开分钟资金历史，程序会跳过它们；不会把估算值伪装成真实数据。若公开源完全不可用，界面会明确标注“演示数据”。

## 数据说明

板块排名会优先使用东方财富公开行情，并在限流时自动切换到同花顺公开网页；指数另有新浪公开行情备用源。不同来源对“大单/资金净额”的统计口径可能不同，界面会显示当前来源。行业与概念板块的成分会重叠，因此板块净额不能直接相加解释为全市场净流入。

本工具仅供信息展示，不构成任何投资建议。

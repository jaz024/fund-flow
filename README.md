# 资金脉络｜A股板块资金流向本地版

这是一个运行在 macOS 或 Windows 本机的中文 A 股板块资金观察工具。它从公开行情页面读取行业与概念板块的资金净额数据，不需要付费 API 或密钥。

## 功能

- 沪、深、京 A 股行业及概念板块资金净流入/净流出排名
- 最新交易日每 5 分钟资金流向气泡回放；固定板块身份，气泡大小、上下位置与颜色随净额连续变化
- 真实五分钟观测自动写入本地 SQLite；关闭后重新打开仍可恢复，已保存的早盘数值不会被午后刷新静默改写
- 最多五个重点板块的日内资金轨迹
- 单个板块近三个月日频资金趋势、5 日及 20 日滚动均线
- 按需生成约 28 秒、9:16、无音乐的 MP4 收盘视频
- 本地缓存；数据源短暂不可用时优先显示最近一次真实缓存

## 启动

### macOS

双击 `start.command`。程序会同时启动本地数据服务和网页，并打开：

`http://127.0.0.1:3000`

首次运行若 macOS 阻止脚本，可在终端中进入本目录并运行：

```bash
./start.command
```

### Windows 10 / 11

1. 安装 [Python 3.10 或更高版本](https://www.python.org/downloads/windows/) 和 [Node.js 22.13 或更高版本](https://nodejs.org/)。
2. 双击 `start-windows.bat`。
3. 首次启动会优先从国内 npm 镜像自动安装项目运行环境，时间取决于网络速度；不需要访问 GitHub，之后启动会更快。

程序准备完成后会自动打开默认浏览器。使用期间请保持启动窗口开启，关闭窗口即可停止本次启动的服务。未安装 FFmpeg 时，行情与图表仍可使用，但 MP4 生成功能不可用。

### 通过 U 盘或 SD 卡发送给 Windows 用户

在 Mac 上双击 `make-windows-transfer.command`，它会在项目文件夹的上一级生成一个名为 `fund-flow-windows-transfer-日期时间.zip` 的干净压缩包。把这个 ZIP 复制到 U 盘或 SD 卡即可。

Windows 用户必须先把 ZIP 完整解压到较短的英文路径（例如 `C:\fund-flow`），再双击其中的 `start-windows.bat`。不要直接在压缩包预览窗口内启动，也不要手动压缩 Mac 上包含 `node_modules` 的整个项目目录。

启动程序会检查依赖是否完整并且属于当前 Windows 处理器。如果收到的压缩包误带了 Mac 依赖或上次安装中断，程序会自动重新构建 Windows 依赖。若仍然失败，请发送同目录的 `startup-windows.log` 以便排查。

## 使用建议

收盘后点击“更新收盘数据”，等气泡回放完成读取后即可点击“生成 28 秒 MP4”。生成的视频同时保存在 `output` 文件夹并由浏览器下载。

分钟回放仅面向最新交易日。程序优先读取东方财富真实分钟资金历史，并将运行期间的东方财富或同花顺完整板块快照每五分钟保存到本机。公开源暂时受限时会保留最近一次已验证结果并继续重试；不会生成、预测或随机补齐气泡与趋势数据。

## 数据说明

板块排名会优先使用东方财富公开行情，并在完整性校验失败时自动切换到同花顺公开网页；指数另有新浪公开行情备用源。不同来源对“大单/资金净额”的统计口径可能不同，因此程序按来源分别保存，不会把不同网站的数值平均或拼成一条连续曲线。行业与概念板块的成分会重叠，因此板块净额不能直接相加解释为全市场净流入。

本工具仅供信息展示，不构成任何投资建议。
